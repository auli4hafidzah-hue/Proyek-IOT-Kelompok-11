1. Pendahuluan dan Tujuan Praktikum

Praktikum Lab-03 Minggu ke-3 berfokus pada implementasi Node Sensor Cuaca Otonom Berdaya Sangat Rendah (Ultra-Low Power Autonomous Weather Station) berbasis mikrokontroler ESP32. Dalam aplikasi nyata perkebunan kopi di area terpencil, ketersediaan daya listrik AC sering kali tidak tersedia. Perangkat IoT dituntut beroperasi mengandalkan pasokan baterai berkapasitas terbatas dengan siklus hidup berbulan-bulan hingga tahunan.

Sistem ini mengintegrasikan sensor barometer presisi Bosch BMP280 dan layar grafis OLED SSD1306 pada satu jalur komunikasi I2C bersama (shared bus), serta menerapkan siklus kerja hemat daya Duty-Cycling menggunakan mode Deep Sleep ESP32 dengan mempertahankan memori riwayat pada RTC Slow Memory (RTC_DATA_ATTR).

Tujuan Spesifik Praktikum:

  1. Mengimplementasikan protokol komunikasi I2C pada bus bersama (SDA: GPIO 21, SCL: GPIO 22) untuk mengendalikan BMP280 (0x76) dan OLED SSD1306 (0x3C) tanpa tabrakan alamat.
  2. Mengembangkan algoritma I2C Scanner untuk mendiagnosis kesehatan koneksi fisik dan integritas sinyal elektrik.
  3. Merancang antarmuka grafis data cuaca (suhu, tekanan, elevasi) yang stabil dan rapi pada layar OLED 128×64 piksel.
  4. Menerapkan arsitektur Deep Sleep dengan pemicu bangun ganda (Timer otomatis 10s dan interupsi tombol eksternal EXT0 GPIO 15).
  5. Membuktikan secara empiris persistensi data telemetri dan penghitung nomor siklus boot pada memori RTC_DATA_ATTR saat mikrokontroler mengalami restart pada fase bangun.

4. Analisis Komprehensif Berbasis Level Taksonomi Bloom (C1 – C6)

4.1 [C1 – Mengingat] Karakteristik Fisik Bus I2C dan Prinsip Addressing 7-Bit

Pertanyaan: Jelaskan prinsip komunikasi perangkat keras bus I2C! Mengapa protokol I2C menggunakan sistem pengalamatan 7-bit, dan apa peran resistor pull-up eksternal?

Jawaban: Protokol I2C (Inter-Integrated Circuit) adalah antarmuka serial sinkron 2 kawat (SDA untuk data dan SCL untuk clock) berarsitektur open-drain. Pada frame transmisi 1 byte pertama, 7-bit teratas (bit 7 hingga bit 1) diperuntukkan bagi alamat unik perangkat budak (slave address), memungkinkan sebanyak 27 = 128 perangkat unik (rentang 0x00 hingga 0x7F). Bit terbawah (bit 0 / LSB) menentukan arah operasi: logika 0 untuk menulis (Master-to-Slave) dan logika 1 untuk membaca (Slave-to-Master). Resistor pull-up berfungsi mengembalikan tegangan jalur ke rel 3,3 V saat tidak ada perangkat yang menarik garis ke ground, mencegah terjadinya korsleting listrik (*bus contention*) saat dua perangkat merespons bus bersamaan.

4.2 [C2 – Memahami] Hirarki Manajemen Daya ESP32 & Alokasi RTC Slow Memory

Pertanyaan: Mengapa variabel SRAM utama terhapus saat Deep Sleep, sedangkan variabel dengan atribut RTC_DATA_ATTR tetap persisten?

Jawaban: ESP32 memiliki pemisahan domain daya fisik (Power Domains). Saat instruksi esp_deep_sleep_start() dieksekusi, sirkuit regulator internal memutus catu daya ke domain digital utama (VDD_DIG) yang memasok CPU Xtensa dan 320 KB SRAM utama. Namun, domain daya RTC (VDD_RTC) tetap disuplai oleh regulator siaga daya rendah (low-power LDO). Variabel dengan atribut RTC_DATA_ATTR secara khusus diarahkan oleh linker kompiler ke segmen memori .rtc.data yang terletak di dalam RTC Slow Memory (kapasitas 8 KB). Dengan demikian, nilainya tetap utuh dan tidak tereset meskipun mikrokontroler mengalami restart pada fase bangun.

4.3 [C3 – Menerapkan] Kalkulasi Elevasi Barometrik & Analisis Umur Baterai

Pertanyaan: Hitunglah estimasi umur pakai baterai lithium 18650 kapasitas 2500 mAh pada mode selalu aktif (60 mA) dibandingkan sistem Deep Sleep praktikum Lab-03 dan implementasi kebun kopi (aktif 6s, tidur 10 menit)!

1. Mode Selalu Aktif (Continuous / Tanpa Sleep — 60 mA):
$$T = \frac{2500\text{ mAh}}{60\text{ mA}} \approx 41,67\text{ jam} \approx \mathbf{1,73\text{ hari (Baterai habis dalam 2 hari)}}$$ 2. Mode Praktikum Lab-03 (Aktif 6 detik @ 55 mA, Tidur 10 detik @ 0,015 mA):
$$I_{\text{avg}} = \frac{(55 \times 6) + (0,015 \times 10)}{16} = \frac{330,15}{16} \approx \mathbf{20,63\text{ mA}} \longrightarrow T = \frac{2500}{20,63} \approx \mathbf{5,05\text{ hari}}$$ 3. Proyeksi Stasiun Cuaca Kebun Kopi (Aktif 6 detik @ 55 mA, Tidur 10 Menit = 600 detik @ 0,015 mA):
$$I_{\text{avg}} = \frac{(55 \times 6) + (0,015 \times 600)}{606} = \frac{339}{606} \approx \mathbf{0,559\text{ mA}} \longrightarrow T = \frac{2500}{0,559} \approx 4472\text{ jam} \approx \mathbf{186,3\text{ hari (~6,2 Bulan)}}$$

4.4 [C4 – Menganalisis] Analisis Integritas Sinyal pada Beban Kapasitif Bus I2C

Pertanyaan: Apa dampak kabel sensor yang terlalu panjang (> 2 meter) pada bus bersama I2C dan bagaimana solusinya?

Jawaban: Kabel yang terlalu panjang menimbulkan kapasitansi parasitik bus yang melampaui batas standar ($C_{\text{bus}} > 400\text{ pF}$). Sesuai hukum pengisian RC ($\tau = R_{\text{pull-up}} \times C_{\text{bus}}$), bentuk gelombang naik sinyal (rise time) menjadi sangat lambat dan melandai, menyebabkan bit ACK gagal terdeteksi dan memicu kondisi I2C Bus Lockup. Solusi perangkat keras mencakup penggantian nilai resistor pull-up menjadi lebih kuat ($1,8\text{ k}\Omega$) atau memasang IC I2C Bus Buffer (seperti P82B715). Solusi perangkat lunak meliputi penurunan kecepatan clock I2C ke 50 kHz dan mengaktifkan batas waktu timeout (Wire.setTimeOut(25)).

4.5 [C5 – Mengevaluasi] Komparasi Pemilihan Display Visual (OLED vs LCD vs E-Paper)

Layar OLED SSD1306 terbukti unggul untuk prototipe berkat konsumsi daya nol saat tidur (DISPLAYOFF), grafis fleksibel, dan waktu respons instan (< 50 ms) dibanding LCD 1602 yang boros lampu latar (backlight). Untuk produksi komersial luar ruangan jangka panjang, layar E-Paper (EPD) menjadi pilihan masa depan terbaik karena sifat bistable display-nya yang mampu mempertahankan gambar tanpa arus listrik sama sekali.

4.6 [C6 – Mencipta] Arsitektur Firmware Resilien: Pemicu Bangun Ganda (Dual Wakeup)

// Deteksi Pemicu Bangun & Klasifikasi Logika Kerja
String periksaPemicuBangun() {
  esp_sleep_wakeup_cause_t pemicu = esp_sleep_get_wakeup_cause();
  if (pemicu == ESP_SLEEP_WAKEUP_EXT0) {
    totalBangunTombol++; // Interupsi Tombol Manual GPIO 15
    return "Tombol EXT0 (GPIO 15)";
  } else if (pemicu == ESP_SLEEP_WAKEUP_TIMER) {
    totalBangunTimer++;  // Alarm Timer Rutin 10 Detik
    return "Timer Otomatis (10s)";
  }
  return "Power-On / Reset";
}
